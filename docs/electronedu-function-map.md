# ElectronEdu 公開功能架構對照

## 查詢結果

公開頁面沒有找到完全名為「近三年命題熱點分析」的功能。

可套用的相近功能架構是：

- 歷年題庫
- 近年配分趨勢
- 多軸診斷
- 弱點分析報告
- 最弱章節排序
- 補強建議
- 章節頁導回題庫練習

## 可套用到公職版的功能

### 1. 歷年題庫

ElectronEdu 主打 95-115 學年度歷年題庫。公職版可改成：

- 考選部行政法試題索引
- 年度、考試、類科、題型篩選
- 試題與答案連結
- 未來接逐題解析與申論擬答

### 2. 近年配分趨勢

ElectronEdu 在科目總複習頁會先告訴學生哪些章節佔比高。公職版可改成：

- 近三年行政法章節出題次數
- 選擇題 / 申論題比例
- 最近一年加權
- 跨考試類科出現次數

### 3. 多軸診斷

ElectronEdu 用 12 軸診斷學生弱點。公職版可改成行政法章節軸：

- 行政處分
- 行政罰
- 訴願
- 行政訴訟
- 行政執行
- 國家賠償
- 行政程序
- 行政契約
- 行政命令
- 行政法基本原則

### 4. 最弱章節排序

ElectronEdu 報告會列出最弱軸與補強建議。公職版可改成：

- 最弱 3 章
- 最常錯題型
- 推薦練習題
- 七天補強任務

### 5. 章節頁導回練題

ElectronEdu 的公開章節頁會把學生導回題庫。公職版可改成：

- 熱點卡片點進章節
- 章節詳情顯示常見考法
- 下方列出對應歷屆題
- 直接進入練習或下載試題

## 產品判斷

ElectronEdu 的重點不是只有題庫，而是把題庫變成「診斷工具」。公職版也應該走這條路：

1. 先用歷年題建立信任。
2. 再用命題熱點讓學生知道先讀哪裡。
3. 接著用練題紀錄找出個人弱點。
4. 最後輸出補強任務，讓學生每天知道該做什麼。
